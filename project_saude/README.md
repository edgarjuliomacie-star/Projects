# Saúde na Mão

Protótipo de um aplicativo web de consultoria de saúde digital para Moçambique, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- **Cadastro do Paciente**: Coleta informações básicas e histórico médico.
- **Triagem de Sintomas**: Perguntas sequenciais sobre sintomas.
- **Hipóteses de Condições**: Geração de possíveis condições baseada em sintomas (simulação).
- **Encaminhamento para Médico**: Simulação de validação por profissional licenciado.
- **Resultado**: Diagnóstico e receita fictícios.
- **Acompanhamento**: Registro de evolução dos sintomas.

## Como Usar

1. Abra o arquivo `index.html` em um navegador web.
2. Preencha o cadastro.
3. Responda às perguntas de triagem.
4. Veja as hipóteses e encaminhe para médico.
5. Receba o resultado e registre acompanhamento.

## Notas

- Este é um protótipo básico. Para produção, integrar com backend, IA real e parcerias legais.
- Seguir regulamentações de saúde e privacidade em Moçambique.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)
